For developers

A few lines. Real payments.

Create charges, refunds and subscriptions with a clean API. Tokenized card data keeps sensitive details off your servers.

Request API access
// create a hosted checkout session
const session = await paypilot.checkout.create({
  line_items: [{ name: 'Annual membership', amount: 12000 }],
  success_url: 'https://yoursite.com/thanks',
  wallets: ['apple_pay', 'google_pay', 'paypilot']
});

// send the customer to pay
redirect(session.url);
